订房红线

不追“网红湖景”，
只确认四件事。

下单前逐条确认：是否供氧、是否有空调/地暖、车能否到门口、免费取消截止时间。国庆期间，石板路拖箱、隔音差和供氧不兑现，比房间少 100 元更影响体验。

每日行程：先适应，再进入高原

每天下午保留机动时间；普达措、雪山和动车以官方预约、天气及身体状况为最终依据。

DAY 01深圳 → 丽江｜落地不赶景点9/26 · 直飞抵达后只做适应与慢逛展开 / 收起
时间安排提示
清晨深圳宝安机场，乘直飞丽江航班。优先 ZH8979（07:15—09:55）或 CZ8581（08:30—11:20）的上午直飞；出发前核对行李额与实际航站楼。
10:30—12:00酒店接机、办理入住或寄存行李。机场到束河 / 古城南侧酒店通常需 40—60 分钟。
下午午休、酒店下午茶或附近慢走。丽江海拔约 2,400 米，第一天下午不要上雪山、不要饮酒。
17:30—19:00束河古镇：青龙桥、四方听音、外围水系。从束河开始比直接冲大研古城更舒服、更安静。
晚上纳西菜或腊排骨火锅，回酒店休息。吃七分饱，保证睡眠，为 Day 2 雪山留体力。
节点特点：束河的重点是水、院落与慢步调；建议 1.5 小时足够，别为了“逛全”走太远。
低海拔适应束河古镇第一晚早睡
DAY 02玉龙雪山 + 蓝月谷｜全程只做雪山9/27 · 不加演出、不加古城夜游展开 / 收起
时间安排提示
07:00早餐后出发至玉龙雪山游客中心。穿防风外套，带水、墨镜、能量零食；旺季务必早出发。
08:30—11:30冰川公园大索道；未约到则换云杉坪。高反敏感者建议直接选云杉坪。不要购买非官方“内部票”。
12:00景区简餐或回白沙附近用餐。不要空腹上高海拔，不饮酒，不跑跳。
13:30—15:30蓝月谷、白水河。沿栈道顺走即可，蓝月谷的水色受天气影响，晴天效果更好。
17:00 后回酒店洗漱、晚餐、早点睡。当天不安排《印象丽江》或古城夜游，避免疲劳叠加。
预约重点：出行前约 7 天开始持续关注“玉龙雪山服务”“丽江旅游集团”等官方渠道。门票、环保车和索道可能分别预约，以当年公告为准。
早场索道冰川公园 / 云杉坪备选蓝月谷
DAY 03玉龙雪山晨光 + 白沙 + 玉湖村 + 丽江古城9/28 · 天气允许就早起看雪峰晨光，白天仍保留村落与古城展开 / 收起
时间安排提示
06:45—08:20白沙 / 玉湖村方向看玉龙雪山晨光，等待雪峰被日出照亮。这是“玉龙雪山版日照金山”，不保证出现，完全取决于云量和能见度；前一晚看天气，阴云厚就取消早起。
08:30—10:50白沙古镇、白沙壁画（若当日开放）、小巷慢走与早餐。晨光结束后顺路逛白沙；壁画如闭馆，不必绕路硬等。
11:20—12:30白沙附近纳西小馆午餐。不排队超过 30 分钟，找就近、卫生和评价稳定的餐厅即可。
13:00—15:20打车至玉湖村：纳西村落、石头民居、雪山脚下田野慢走。从白沙过去通常不远；不去收费骑马或拉市海项目，步行与村落视野已足够。
16:00—17:00回酒店短暂休息、换衣服。早起看晨光后必须保留这段休息，不让傍晚古城变成连续暴走。
17:30—20:00丽江古城南门 → 木府外围 → 忠义市场 → 小巷。傍晚再进城，不强行挤四方街；20:30 前回酒店。
调整后：Day 3 成为完整的“纳西村落 + 雪山脚下 + 傍晚古城”主题日，景观层次更丰富，但单段步行仍控制在轻松范围。
白沙雪山视野玉湖村古城南门进入
DAY 04丽江 → 上虎跳峡 → 香格里拉｜顺路完成峡谷转场9/29 · 不再丽江往返虎跳峡，把路程用在去香格里拉展开 / 收起
时间安排提示
08:00丽江酒店早餐、退房，专车出发前往虎跳峡。提前确认车辆、驾驶员资质与行李空间；当天不坐动车，采用丽江→虎跳峡→香格里拉一车到底。
10:30—12:30上虎跳峡：观景台、虎跳石、金沙江峡谷核心段。按体力选台阶或景区扶梯；只走核心景观，不安排中虎跳徒步。
12:30—13:30桥头镇或景区附近午餐。简单补给，别为网红餐厅久等；高原转场日保持清淡。
13:30—16:30继续前往香格里拉，酒店办理入住。全程受路况影响，按 4—5 小时以上转场预留；到达约 3,200 米高原后不再赶景点。
17:30—18:15松赞林寺外围 / 拉姆央措湖周边观景位轻看。只看外围建筑群与远景，不进主殿、不走长台阶；若头痛、气促或疲劳，直接取消外出。
晚上清淡藏餐 / 汤锅，早睡。不饮酒、不洗长时间热水澡，为次日无底湖的高海拔轻徒步留足适应空间。
调整价值：虎跳峡从“丽江往返一日”变成“顺路转场景观”，省掉一段重复路程；但这天仍是全程较长的用车日，必须选择正规舒适车辆。
上虎跳峡虎跳石顺路转场香格里拉适应夜
DAY 05无底湖一日｜冷杉森林与高原湖轻徒步9/30 · 海拔更高的一天，只走环湖基础线，不加仙女湖/天池展开 / 收起
时间安排提示
08:00酒店早餐后，正规拼车 / 包车出发前往无底湖。市区单程约 2—2.5 小时；无公共交通，优先正规小团或SUV包车，不建议自行驾驶末段碎石路。
10:30—11:00抵达湖区、上洗手间、补水并适应海拔。无底湖约 3,800 米上下，先静坐 20—30 分钟；有头痛、胸闷或恶心就不进环湖线。
11:00—14:00无底湖基础环湖：木桥、苔藓冷杉林、牧场、湖畔观景点。只走约 3—5 公里基础环线，每 40 分钟休息；不去仙女湖 / 天池等进阶线，不骑马替代徒步。
14:00—14:40湖边简餐与热饮补给。自备水、保温杯、巧克力/能量棒；湖区补给、厕所和信号都有限，垃圾自行带回。
15:00—17:30适时返程香格里拉市区，回酒店休息。高原山路与天气变量大，雨雪/大雾时直接改为松赞林寺深度游+独克宗古城，不冒险硬去。
晚上酒店晚餐、补水、早睡。第二天普达措并需动车返丽江，今晚不要饮酒或熬夜。
关键取舍：无底湖比纳帕海更原生态，但也更高、更远、信号更弱。它适合天气稳定且第一晚无明显高反的前提；若不满足，直接启用市区备选，不要硬冲。
海拔约3,800米冷杉苔藓森林基础环湖线正规拼车/包车

DAY 01 · 深圳 → 丽江 / 束河

不买景区票，只安排机场与市内接驳

无需门票酒店接机 / 滴滴

怎么走：抵达丽江三义机场后，优先订酒店接机；没有接机就用滴滴/高德打车去酒店，通常约40—60分钟。傍晚酒店打车到束河古镇，束河免费进入，步行游览即可。

怎么买：机场接机最好随酒店房订单预订；若单叫车，落地后再下单即可，不用提前买接送“套餐”。

第一天下午不要买拉市海骑马、旅拍或一日游产品，先适应海拔并留给航班延误缓冲。
DAY 02 · 玉龙雪山 + 蓝月谷

本行程最需要提前预约的一天

实名预约官方小程序

门票怎么买：提前约7天关注“玉龙雪山服务”和“丽江旅游集团”微信小程序。通常需分别确认进山票/环保车与索道票：冰川公园大索道抢不到就立刻改云杉坪，蓝月谷随进山票和环保车游览。

交通怎么走：优先酒店协助订正规雪山小团或往返拼车；也可在“丽江旅游集团”/正规平台订古城往返直通车。当天07:00左右从酒店出发，别自驾去旧西南门碰运气。

不要买民宿、出租车或陌生人承诺的“内部票/代抢票”。票务规则和放票时点以出发前7天官方公告为准。
DAY 03 · 白沙 / 玉湖村 / 丽江古城

免费景点为主，交通靠打车最省心

多数免费滴滴 / 包车半日

门票怎么买：白沙古镇、玉湖村和丽江古城公共区域通常免费；白沙壁画是否开放、是否收费或需现场预约，以当天公告为准，不把它作为必须完成项。

交通怎么走：酒店→白沙、白沙→玉湖村、玉湖村→酒店建议滴滴/高德分段叫车；若不想频繁等车，可让酒店安排半日正规包车。傍晚再从酒店打车到丽江古城南门。

看晨光日照时，只在前夜天气晴/少云时早起；阴云厚就按正常时间去白沙，不产生任何损失。
DAY 04 · 丽江 → 虎跳峡 → 香格里拉

专车一车到底，避免拆成公交换乘

虎跳峡门票正规专车

门票怎么买：上虎跳峡门票及景区扶梯/观光交通可在“游云南”、景区官方渠道或正规OTA预订；若专车供应商代订，要在确认单写清门票、扶梯、停车费是否已含。

交通怎么走：让酒店或正规旅行社安排“丽江酒店→上虎跳峡→香格里拉酒店”包车，确认车辆、司机营运资质、乘客保险、无购物条款和最终到店时间。不要当天临时在古城找拼车。

这天不买“中虎跳徒步”或额外峡谷项目；只走上虎跳核心段，确保傍晚抵达香格里拉后有适应高原的时间。
DAY 05 · 无底湖基础环湖

没有常规公共交通，提前锁正规小团

拼车 / SUV包车基础环湖

费用怎么买：无底湖通常没有统一的大门票体系，但可能有村民卫生/环保管理费；优先通过携程景区直通车、正规户外小团或酒店推荐的有资质拼车预订。下单前问清是否含往返车、环保/卫生费、保险和取消规则。

交通怎么走：从香格里拉市区出发约2—2.5小时，末段可能有碎石路，选SUV或正规户外小团；不建议自驾轿车，不建议无信号区域临时换车。

海拔约3,800米。若抵达首晚有明显头痛/恶心，或当日雨雪、大雾，直接取消无底湖，改松赞林寺深度游+独克宗，钱比身体更容易补回来。
DAY 06 · 普达措 → 动车回丽江

先订晚班动车，再反推景区离园时间

普达措实名预约12306晚班动车

门票怎么买：提前通过“普达措国家公园”官方渠道、“游云南”或正规OTA实名预约门票+环保车；当前常见参考约¥138/人，早场入园更适合当天转场。确认最晚入园、末班环保车及当天开放区域。

交通怎么走：酒店→普达措可订景区直通车或正规包车，约40分钟。16:00离园后约17:00回市区取行李；动车优先反向锁 C442（19:02→20:15）或 C990（20:25→21:48）等晚班，再去排普达措。

如果12306只剩17:25等早班，不能同时满足“普达措玩到16:00”。此时优先提前离园或调整无底湖日，绝不压缩进站时间。
DAY 07 · 丽江 → 深圳

无景区门票，送机只留一个目的地

酒店送机 / 滴滴航班值机

怎么走：酒店退房后寄存行李，最晚在航班起飞前约2.5—3小时从酒店出发去三义机场。优先预订酒店送机；若用网约车，提前半天预约并给国庆堵车留余量。

怎么买：不需要再买景区票。若尚未购买行李额、选座或航班延误险，这天前一晚在航司官方App一次性处理。

返程日不安排玉龙雪山、白沙或虎跳峡。把时间留给机场缓冲，才是这条线路最值的“保险”。

高反、天气与避坑

这条线最大的变量不再是大理的拥堵，而是香格里拉的海拔与高原天气。

高反预案

  • 香格里拉抵达日只安排松赞林寺外围短看；不洗长时间热水澡、不喝酒、不剧烈运动。
  • 无底湖与普达措连续两天海拔较高；出现明显头痛、胸闷或恶心时，优先取消无底湖或缩短步道，不要硬撑。
  • 持续呕吐、明显气促、意识异常或走路不稳，不要继续游玩，应就医或立即下降到低海拔。
  • 氧气瓶只能缓解症状，不能替代停止活动和就医判断；慢、暖、补水、睡眠才是核心。

避坑与天气备选

  • 不购买玉龙雪山“内部票”、不跟街头拉客车；抢不到冰川大索道就改云杉坪。
  • 无底湖海拔约3,800米、末段路况与信号都较弱；前一晚有明显高反或遇雨雪/大雾，就改松赞林寺深度游 + 独克宗，不硬去。
  • 普达措若遇强降雨，减少户外步道；若10/1晚班动车无法衔接，提前离园或改动无底湖日，绝不压缩进站时间。
  • 丽江古城重点避开酒吧街深处与拖箱困难的石板巷；古城南门进入、傍晚离开更舒服。
